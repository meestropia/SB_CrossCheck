1. The program accepts the .xls output from the Hypack Cross Check Analysis Tool.

2. Reads the result and test for the overall accuracy of the area based on NAMRIA Standards for Hydrographic Surveys (NSHS).

3. Displays the result and save a .csv file of the result and also computes for the accuracy of each line.
4. Also saves the screenshot of the window for reporting purposes.
